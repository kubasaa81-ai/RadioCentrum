# Radio Centrum

Dwie aplikacje:

* **RadioCentrum-RADIO.apk** – na radio samochodowe z Androidem. Zakładki: Powiadomienia, Połączenia, Kontakty, Klawiatura, Ustawienia. Powiadomienia i połączenia wyskakują jako okienko nad nawigacją.
* **RadioCentrum-TELEFON.apk** – na telefon. Działa w tle i wysyła do radia SMS-y, powiadomienia, rozmowy, historię połączeń i kontakty, a z radia przyjmuje „zadzwoń / odbierz / odrzuć”.

Połączenie: Bluetooth (Android radia), zapasowo Wi-Fi (radio na hotspocie telefonu + 6-cyfrowy kod).

Gotowe pliki APK: zakładka **Releases** (budowane automatycznie przez GitHub Actions po każdej zmianie).
